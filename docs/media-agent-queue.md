# Media documentation moved

Den kanoniske tekniske runbook for media/hero-pipelinen ligger nu i `docs/backend/media.md`.

Almindelige news-producere skal bruge hero-kontrakten i `docs/automations/news-task.md` og må ikke åbne backend-runbooken som en del af normal promptkontekst.

Denne fil beholdes midlertidigt som compatibility-pointer for ældre referencer og kan slettes, når alle callers/docs er migreret.

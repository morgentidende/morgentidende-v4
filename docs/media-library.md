# Media documentation moved

Den kanoniske backend-runbook for media, hero-rettigheder, arkivering, fallback, legacy og worker-flow ligger nu i `docs/backend/media.md`.

Almindelige news-producere skal ikke læse backend-runbooken; producer-kontrakten ligger i `docs/automations/news-task.md`.

Denne fil beholdes midlertidigt som compatibility-pointer for ældre referencer og kan slettes, når alle callers/docs er migreret.
